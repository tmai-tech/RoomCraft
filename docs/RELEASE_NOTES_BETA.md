# RoomCraft 1.0.0-beta.1

Thank you for testing RoomCraft!

## What's in this build

- **Scan** your room with the camera → top-down blueprint  
- **Review** plan, fix scale, pick which furniture to keep  
- **Arrange** furniture (drag, rotate, snap, undo)  
- **Auto-arrange** bedroom / living / office  
- **Layout score** and tips (overlaps, door blocked, crowded)  
- **Export** plan as PNG and share  

## Tips

1. Add a **Gemini API key** in Settings for AI scan  
2. After scan, set a known wall length for better scale  
3. Use **Pan** vs **Select** tools on the blueprint
